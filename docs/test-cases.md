# Набор тестовых сценариев

## Данные

Автоматические тесты используют SQLite-файл во временной папке Pytest, который удаляется средой после теста. Пользователи и сообщения создаются только для изолированных тестов. Для HTTP- и WebSocket-клиента применяется FastAPI TestClient. В качестве отдельного примера регистрации в тестах задан пароль `secure-pass-123`; секретные ключи и реальные пользовательские данные не используются.

## Сценарии и результаты последнего запуска

| № | Сценарий | Ожидаемый результат | Результат |
|---:|---|---|---|
| 1 | Запрос `GET /health` | HTTP 200, статус healthy | Пройден |
| 2 | Регистрация имени с пробелами и разным регистром | HTTP 201, имя нормализовано, пароль не выдан | Пройден |
| 3 | Повторная регистрация того же имени | HTTP 409 | Пройден |
| 4 | Вход с правильным паролем, чтение `/auth/me` | HTTP 200, профиль соответствует пользователю | Пройден |
| 5 | Вход с неверным паролем и запрос `/auth/me` без токена | HTTP 401 | Пройден |
| 6 | Preflight-запрос с разрешённым Vite Origin | HTTP 200, CORS Origin разрешён | Пройден |
| 7 | Создание таблиц и сохранение связанного сообщения | Созданы четыре таблицы; сообщение читается из БД | Пройден |
| 8 | Создание чата, подключение двух участников по WebSocket и отправка сообщения | Оба участника получают сообщение; оно есть в истории | Пройден |
| 9 | Чтение истории и WebSocket-подключение пользователя вне чата | HTTP 404 для истории, WebSocket close 4403 | Пройден |

Команды, использованные в проекте: `python -m pytest -q` из `backend`; `pnpm build` и `pnpm lint` из `frontend/client`. По зафиксированному запуску Pytest завершился с результатом `9 passed`, сборка клиента и Oxlint завершились без ошибок. Тест PostgreSQL в этот набор не входит.
