# Базовый замер характеристик

## Методика

Скрипт `scripts/benchmark.py` отправляет HTTP GET-запросы к `/health`, измеряет время каждого запроса на клиенте и считает медиану, 95-й процентиль, среднее, минимум, максимум и пропускную способность. Перед измерением выполняются до пяти разогревочных запросов. Для параллельности используется пул потоков Python. Скрипт не создаёт записи и не меняет данные приложения.

## Результат локального запуска

Замер выполнен 26 ноября 2026 года на `http://127.0.0.1` с временной SQLite-базой, 100 измеряемыми запросами и параллельностью 8. Окружение: Windows 11 Pro 10.0.26300, Python 3.13.15, Uvicorn и SQLite.

| Показатель | Результат |
|---|---:|
| Успешные ответы | 100 из 100 |
| Общее время 100 запросов | 0,057 с |
| Пропускная способность в этом запуске | 1 754,12 запроса/с |
| Минимальная задержка | 1,432 мс |
| Средняя задержка | 4,316 мс |
| Медианная задержка | 3,682 мс |
| 95-й процентиль | 11,593 мс |
| Максимальная задержка | 13,766 мс |

Маршрут `/health` возвращает постоянный JSON-ответ и не обращается к базе данных; его работа имеет постоянную асимптотическую сложность O(1). Полученные цифры являются локальным базовым замером одного короткого запуска на loopback-интерфейсе, а не нагрузочным пределом сервера и не прогнозом для сети или PostgreSQL.

Повторить замер можно после запуска backend командой:

```powershell
python scripts/benchmark.py --url http://127.0.0.1:8000/health --requests 100 --concurrency 8
```
