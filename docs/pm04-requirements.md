# Требования к развитию мессенджера

## Основание

Проект выполняется как учебная работа по теме «Свой мессенджер». Отдельный внешний заказчик не заявлен. Требования ниже сформулированы для пользовательского сценария этого учебного проекта и не приписываются конкретной организации.

## Потребность пользователя

При временном обрыве сети пользователь должен понимать, что чат отключён, и иметь возможность восстановить соединение без перезагрузки страницы. После восстановления соединения необходимо снова запросить историю выбранного чата, чтобы показать сохранённые сообщения.

## Критерии приёмки

1. При потере WebSocket-интерфейс отображает состояние «не в сети».
2. В отключённом состоянии доступна кнопка «Повторить подключение».
3. Нажатие кнопки повторно загружает историю выбранного чата и открывает WebSocket-соединение.
4. При успешном открытии соединения интерфейс показывает состояние «в сети», а поле отправки сообщений становится доступно.

## Изменённый компонент

В `frontend/client/src/App.tsx` добавлено повторное выполнение эффекта загрузки истории и подключения WebSocket по отдельному счётчику попыток. В заголовке чата при отключённом соединении отображается кнопка повторного подключения. Стили кнопки находятся в `App.css`. Сборка TypeScript/Vite и Oxlint используются для проверки клиентского кода.
