# Защита мессенджера

## Применённые средства

- Пароли хешируются библиотекой `pwdlib` с рекомендуемой схемой Argon2; исходный пароль не записывается в модель и не входит в ответ API.
- После входа сервер выдаёт подписанный JWT с ограниченным сроком действия (по умолчанию 60 минут). Защищённые HTTP-маршруты проверяют подпись, срок действия и существование пользователя.
- WebSocket проверяет токен при соединении и отклоняет недействительный токен кодом 4401.
- Доступ к истории и WebSocket разрешается только пользователю, состоящему в соответствующем чате. Для HTTP отсутствующее членство скрывается ответом 404; для WebSocket используется код 4403.
- Pydantic проверяет входные данные: длину имени и пароля, заголовок чата, число участников, длину и пустое содержимое сообщения.
- CORS разрешает только два локальных адреса клиента Vite. Секрет JWT и строка подключения находятся в `.env`, который исключён из Git; сценарий начальной настройки генерирует случайный ключ, если файл ещё не создан.

## Проверки

Pytest проверяет отказ при неверном пароле, коротком пароле регистрации и недействительном JWT, невозможность доступа к чату постороннего пользователя, отказ WebSocket без токена, а также отклонение пустых и слишком длинных сообщений. Невалидные сообщения не сохраняются, после отказа соединение принимает корректное сообщение. Последний запуск набора: 13 тестов пройдены.

## Ограничения

В учебном MVP нет восстановления пароля по электронной почте, подтверждения адреса и ограничения числа попыток входа. Эти функции не описываются как реализованные. JWT хранится в браузере и передаётся при WebSocket-подключении через query-параметр; приложение рассчитано на локальный учебный запуск, а не на публичное production-развёртывание.
